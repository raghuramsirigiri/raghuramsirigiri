### 🎯 What does a Product Data Scientist do?
A product data scientist analyzes user journeys, defines core KPIs, and designs A/B tests to inform product strategy. In my role, I focus on:
- **Product Analytics:** Designing A/B tests and conducting causal inference to improve user retention and engagement.
- **Marketing Analytics:** Building predictive models for customer churn and lifetime value (LTV) to optimize customer segmentation and acquisition channels.
- **Actionable Insights:** Translating rigorous statistical findings into clear, interactive dashboards and compelling data narratives for cross-functional stakeholders.

### 🛠️ Core Competencies

- **Machine Learning:** Predictive Modeling, Customer Segmentation Machine Learning, Classification, Regression
- **Data & Visualization:** Python (Pandas, Scikit-learn), SQL, Dashboard Design (Tableau/Looker/PowerBI)
